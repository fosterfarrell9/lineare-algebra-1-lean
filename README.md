# Lineare Algebra 1 – Beispiele in Lean

Begleitmaterial zur Vorlesung „Lineare Algebra 1“ (Wintersemester 2026/27, Denis Vogel).

- `beweise-in-lean.lean`: der Kontrapositions- und der Widerspruchsbeweis aus Beispiel 1.12 des Skripts, dazu die Einzeiler-Fassung mit einem Satz aus Mathlib.

Die Datei lässt sich ohne Installation im Browser öffnen:
[live.lean-lang.org](https://live.lean-lang.org/#project=mathlib-stable&url=https%3A%2F%2Fgithub.com%2Ffosterfarrell9%2Flineare-algebra-1-lean%2Fblob%2Fmain%2Fbeweise-in-lean.lean)

Geprüft mit Lean 4 und Mathlib (Stand September 2026).
